What this page is for

This page loads the GTM web container only. It does not load amzn.js. Events reach Amazon through the tagging server, which is what makes it useful for testing the server-side tag template.
  1. Web container: add a GA4 Configuration tag, All Pages, with server_container_url set to your tagging server under Fields to Set.
  2. Server container: confirm the GA4 client is enabled so it claims the incoming request.
  3. Server container: add the Amazon Advertising Tag - Server Side, with a trigger on the event you want.
  4. Open server container Preview, then use the buttons below and read the outgoing HTTP request.
